# AIトレーニングコーチ(スクワット版)

iPhone のブラウザだけで動くパーソナルトレーニングコーチです。GitHub Pages に置けばどこでも使えます。

- **姿勢推定**: MediaPipe Pose Landmarker(端末内で処理、映像は外部に送らない)
- **判定**: `squat.js` が関節角度からレップを数え、深さ・前傾・速さを判定
- **即時の声かけ**: 回数と「もう少し深く」「胸を起こして」をブラウザの読み上げ機能で即座に再生
- **AIコーチ**: セット終了時と話しかけた時だけ、数値の要約を Gemini API に送って声かけを作る

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `app.js` | カメラ、MediaPipe、音声入出力、Gemini 連携 |
| `squat.js` | スクワット判定ロジック(ライブラリ非依存) |
| `test/squat.test.mjs` | 判定ロジックのテスト(`node test/squat.test.mjs`) |

## GitHub Pages で公開する

1. 新しいリポジトリを作り、上のファイルをそのまま置く(無料プランの場合はリポジトリを公開にする必要あり)
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

## Gemini APIキー

- キーは**リポジトリに書かない**。アプリ右上の ⚙ から入力すると、その端末のブラウザ内(localStorage)にだけ保存されます
- 念のため Google Cloud コンソールの「認証情報」でキーを開き、「アプリケーションの制限」を **ウェブサイト** にして `https://<ユーザー名>.github.io/*` だけを許可しておくと、キーが漏れても他のサイトからは使えません
- モデル名は ⚙ から変更できます(初期値 `gemini-2.5-flash`)

## 使い方

1. 「カメラとコーチを起動」をタップし、カメラとマイクを許可
2. スマホを**体の真横** 2〜3m の床や台に置き、頭から足首まで映す
3. 「セット開始」と話しかける(またはボタン)→ スクワット
4. 最後のレップから8秒立ったままだと自動でセット終了 → コーチがフィードバック
5. 「膝が痛くならないコツは?」などと話しかけると、今日の記録を踏まえて答えます

音声コマンド: 「セット開始」「セット終了」「何回?」(それ以外は AI コーチへの質問になります)

## 判定の基準(`squat.js` の `DEFAULTS`)

| 項目 | 初期値 | 意味 |
|---|---|---|
| `depthAngle` | 100° | 膝の最小角度がこれ以下なら十分な深さ(⚙で変更可) |
| `leanWarn` | 55° | 上体の前傾がこれを超えたら「胸を起こして」 |
| `minRepSec` | 1.2秒 | 1レップがこれより速いと「ゆっくり下ろして」 |
| `standAngle` / `descendAngle` | 160° / 140° | 立っている/しゃがみ始めの判定 |

角度は横から撮った2D画像上の値です。斜めから撮ると誤差が大きくなります。
